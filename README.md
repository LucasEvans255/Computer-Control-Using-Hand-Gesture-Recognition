# Computer-Control-Using-Hand-Gesture-Recognition
A system that detects where your hand is in the webcam's view and performs different actions on the computer depending on what gesture you are making.

This was my NEA (Non Examinable Assessment) for my AQA Computer Science A Level, in which I got a mark of 69/75 for this project, and achieved an A* grade.

The entire writeup including market research, the design and testing process can be found in NEA.docx.
